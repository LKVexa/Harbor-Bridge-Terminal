# Dependencies and Environment

## Runtime
- CPython ≥ 3.10 (tested 3.11.15 in this build). Standard library only.
- POSIX host for the control socket and process adapter; Linux + systemd for watchdog/notify integration.

## Optional: pk_core (conformance integration)
`component.py`, `contract.py` and `tests/test_component.py` integrate with the external Post-Kubernetes `pk_core` framework (`pk_core.checklist`, `pk_core.component`). It is **not** on PyPI and is not included. Install it from the Post-Kubernetes series distribution and set `PK_CORE_PATH` or put it on `PYTHONPATH`; `verify.py` then runs the 100-check gate automatically. Without it, the package imports and all other suites run.

## Development / CI
Pinned in `requirements-dev.txt` (ruff, mypy, coverage). Machine-readable inventory: `sbom.cdx.json` (CycloneDX 1.5), regenerated by `tools/build_release.py`.

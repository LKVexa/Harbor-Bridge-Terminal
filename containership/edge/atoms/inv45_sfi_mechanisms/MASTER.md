# INV-45 SFI mechanisms — master index (A1)

**Version 4.3.0.** This file is the authoritative map of the repository. `README.md` is the quick start.

## Purpose and trust boundary

INV-45 strengthens multi-tenant WebAssembly execution with software fault isolation: each tenant module is
confined to a partition of linear memory by heap masking, and nothing executes unless it was verified.

* **Enforcement boundary (authoritative):** `production/` — the strict Wasm parser/validator
  (`wasm.py`), the rewriter and the *independent* verifier (`sfi.py`), sealed descriptors and trust
  material (`trust.py`), and the trusted loader (`service.py::SfiService.load`). The verifier examines the
  exact bytes that are later executed; the loader re-binds them by SHA-256.
* **Reference model (non-authoritative):** `sfi_core.py` — the 4.2.0 Python model, kept for its report
  shapes and as a differential oracle for the mask formula. It is never on the enforcement path.
* **Checklist binding:** `component.py`, `contract.py` — require the external `pk_core` (absent here).

## Lifecycle / data flow

untrusted artifact → **authenticate** caller (identity token) and artifact (Ed25519 statement) →
**admission** (quotas) → **quarantine / anti-rollback** checks → **rewrite** (untrusted helper) →
**verify** (trusted; proof `PK_SFI_PROOF/1`) → **seal** (HMAC descriptor bound to digest, profile, proof,
config, tenant, version, nonce, expiry) → **authorize load** (`sfi.load` @tenant @digest, replay, digest,
profile/config binding, re-verify, floor) → **execute** (fresh `node --permission` process per job) →
**telemetry** (audit chain, metrics, logs, traces, explain) → **quarantine / disable** at any point.

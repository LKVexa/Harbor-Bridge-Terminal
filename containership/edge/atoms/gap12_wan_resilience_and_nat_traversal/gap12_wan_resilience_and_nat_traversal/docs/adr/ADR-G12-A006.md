# ADR-G12-A006: protocol mapping and intentional deviations

- **Version:** 4.3.0 (this decision is versioned with the package; supersede with a new ADR, do not edit)
- **Status:** recorded by the builder; owner approval pending (no owner is assigned)
- **Specification:** RFC 4787, RFC 5780
- **Implemented by:** `wan.natclass.classify`, `wan.natclass.Classification`, `wan.natclass.network_fingerprint`

## Decision
Implement the subset described in the implementing module's docstring (message types, attributes, timers and
error handling are listed there and exercised by the tests tagged for G12-A006).

## Intentional deviations / unsupported sub-cases
- classification without an RFC 5780 (OTHER-ADDRESS / CHANGE-REQUEST) capable server

## Consequences
Unsupported sub-cases return `UNSUPPORTED` or a specific `NET_*`/`DEP_*` reason; they never fall back silently.

# G12-A002 — TURN client (P0)

_Generated from `evidence/registry.py`; lifecycle **validation**._

## Normative requirement
- **Success:** an authenticated allocation whose relayed address carries data both ways under a permission, refreshed before expiry and torn down with lifetime=0.
- **Failure:** any other outcome, reported with a registered reason code (`wan/reasons.py`); failures never silently fall back to a less-trusted path.
- **Degraded:** a dependency is down/stale (see `wan.state.degraded_policy`); existing trusted sessions continue until trust expiry, new ones are refused.
- **Unsupported:** TURN over TCP/TLS/DTLS (RFC 6062), EVEN-PORT, DONT-FRAGMENT, dual-family allocations, OAuth third-party auth, server failover — reported as `UNSUPPORTED` / NOT-EVIDENCED, never emulated.
- **Policy rejection:** `POLICY_*` reason codes (egress, mechanism disabled, quarantine, untrusted peer, config rejected).

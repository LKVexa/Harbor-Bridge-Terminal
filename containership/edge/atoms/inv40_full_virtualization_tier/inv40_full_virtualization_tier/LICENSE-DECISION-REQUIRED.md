# REPO-005 — licence not chosen

This repository has no LICENSE file and none was added: choosing a licence for the owner's code is the owner's decision.
It contains no third-party code (all v4.3.0 additions are new, stdlib-only), so `THIRD-PARTY-NOTICES.md` records "none".
`pyproject.toml` declares `license = {text = "UNLICENSED - all rights reserved pending owner decision"}` so tooling does not infer a permissive licence.

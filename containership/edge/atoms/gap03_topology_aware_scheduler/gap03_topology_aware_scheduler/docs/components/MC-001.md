# MC-001 — Versioned wire schemas

**Modules:** `controlplane/wire.py`, `controlplane/canonical.py`, `controlplane/bindings.py`, `controlplane/gen_bindings.py`

## Scope
Normative GAP03-IDL/1 schemas, bounded parser, canonical serialization, registry, negotiation, migration for PK_TOPOLOGY/1, PK_LOCALITY_COST/1, PK_FAIR_SHARE/1.

## Non-goals
Transport binding (HTTP/gRPC framing) and authentication of the carrying channel.

## Owned by adjacent services
Transport + identity: MC-012; peers own their emitted payloads.

## Interfaces

| Interface | Protocol / version | AuthN/Z | Timeout | Retry | Failure semantics |
|---|---|---|---|---|---|
| PK_TOPOLOGY/1.1 | canonical JSON application/vnd.pk.topology.v1+json | signed envelope (MC-012) when crossing trust boundary | caller deadline | idempotent read | UNSUPPORTED_VERSION / INVALID_ARGUMENT |
| PK_LOCALITY_COST/1.0 | canonical JSON | as above | caller deadline | idempotent | INVALID_ARGUMENT |
| PK_FAIR_SHARE/1.0 | canonical JSON | as above | caller deadline | idempotent | INVALID_ARGUMENT |

## Data / state model
Schema {id, major, minor, media_type, reserved[], fields{type, unit, min, max, max_len, pattern, enum, required, default, since}}; payload identity = sha256(canonical bytes).

## Invariants → enforcing tests

- Malformed/duplicate/NaN/over-depth/over-size payloads never reach scheduling logic — `test_mc001_parser_rejects_malformed_and_adversarial`
- Canonical encoding is unique per value — `test_mc001_canonical_serialization_is_deterministic`
- Minor versions are additive only — `test_mc001_compatibility_gate_and_api_reference`
- Generated bindings match the schema digests — `test_mc001_generated_bindings_in_sync_and_pinned`

## Threat model (STRIDE + replay / stale-state / cross-tenant)

| Threat | Treatment |
|---|---|
| spoofing | Callers authenticate with GAP03-ID/1 Ed25519 credentials; unknown issuer/kid/alg rejected (MC-012). |
| tampering | Canonical-JSON digests bind requests/artifacts; hash-chained WAL detects on-disk edits (MC-001/004). |
| repudiation | Privileged actions are written to the tamper-evident audit log before commit (MC-013). |
| disclosure | Error payloads, logs and explain output are redacted/pseudonymised (MC-014/020/024). |
| dos | Size/depth/cardinality bounds on every input; admission + rate limits (MC-001/025). |
| elevation | Least-privilege RBAC with two-person rule for high-blast-radius operations (MC-002/017). |
| replay | Single-use nonces with bounded cache; idempotency keys return the original outcome (MC-012/026). |
| stale_state | Generation / revision / fencing preconditions reject stale decisions (MC-004/005/006). |
| cross_tenant | Tenant-scoped reads; reservations of other tenants are never spendable (MC-003/005). |

## Cryptography / secrets
Not applicable - holds no keys; integrity via canonical digests.

## Sensitive data
No tenant secrets; identifiers pseudonymised in telemetry.

## Failure modes

| Failure | Behaviour | Mode |
|---|---|---|
| invalid input | raises SchedulerError INVALID_ARGUMENT | fail-closed |
| overload | bounded by admission before invocation | bounded |
| unknown peer version | negotiation fails before side effects | fail-closed |

## Concurrency / idempotency / retry
Pure/immutable; safe for concurrent use; no retries or cancellation state.

## Threat model (STRIDE + replay / stale-state / cross-tenant)

| Threat | Treatment |
|---|---|
| spoofing | Not applicable at this layer: in-process library without network ingress; callers are the authenticated service boundary. |
| tampering | Not applicable at this layer: in-process library without network ingress; values are immutable (frozen dataclasses / tuples). |
| repudiation | Not applicable at this layer: in-process library without network ingress; decisions are recorded by the explain store of the caller. |
| disclosure | Not applicable at this layer: in-process library without network ingress; holds no tenant secrets; telemetry passes through privacy.sanitize. |
| dos | Not applicable at this layer: in-process library without network ingress; inputs are bounded by admission limits before reaching it. |
| elevation | Not applicable at this layer: in-process library without network ingress; exposes no privileged operation. |
| replay | Not applicable at this layer: in-process library without network ingress; pure function of its inputs; replay is harmless. |
| stale_state | Not applicable at this layer: in-process library without network ingress; keys/results include generations so stale inputs cannot match. |
| cross_tenant | Not applicable at this layer: in-process library without network ingress; never keys by tenant identity. |

# MC-012 — Identity, attestation, provenance

**Modules:** `controlplane/identity.py`, `controlplane/ed25519.py`

## Scope
SPIFFE-style identities, Ed25519 tokens/artifacts, trust store with rotation/revocation, replay protection, attestation.

## Non-goals
Certificate issuance / workload attestation infrastructure (external).

## Owned by adjacent services
Issuers are external trust roots.

## Interfaces

| Interface | Protocol / version | AuthN/Z | Timeout | Retry | Failure semantics |
|---|---|---|---|---|---|
| TrustStore.verify_token | GAP03-ID/1 token | self | n/a | n/a | UNAUTHENTICATED/REPLAY_DETECTED |
| sign_artifact/verify_artifact | statement + Ed25519 signature | self | n/a | n/a | UNAUTHENTICATED/INTEGRITY_FAILURE |

## Data / state model
claims {alg, iss, kid, sub, aud, roles, iat, nbf, exp, nonce, req?}; key {kid, public, not_before, not_after, revoked}.

## Invariants → enforcing tests

- Only Ed25519 accepted (no downgrade) — `test_mc012_token_verification_negative_matrix`
- Revoked key / removed root stops verifying immediately — `test_mc012_rotation_overlap_revocation_and_root_removal`
- Signature implementation matches RFC 8032 — `test_mc012_ed25519_rfc8032_vector`

## Threat model (STRIDE + replay / stale-state / cross-tenant)

| Threat | Treatment |
|---|---|
| spoofing | Callers authenticate with GAP03-ID/1 Ed25519 credentials; unknown issuer/kid/alg rejected (MC-012). |
| tampering | Canonical-JSON digests bind requests/artifacts; hash-chained WAL detects on-disk edits (MC-001/004). |
| repudiation | Privileged actions are written to the tamper-evident audit log before commit (MC-013). |
| disclosure | Error payloads, logs and explain output are redacted/pseudonymised (MC-014/020/024). |
| dos | Size/depth/cardinality bounds on every input; admission + rate limits (MC-001/025). |
| elevation | Least-privilege RBAC with two-person rule for high-blast-radius operations (MC-002/017). |
| replay | Single-use nonces with bounded cache; idempotency keys return the original outcome (MC-012/026). |
| stale_state | Generation / revision / fencing preconditions reject stale decisions (MC-004/005/006). |
| cross_tenant | Tenant-scoped reads; reservations of other tenants are never spendable (MC-003/005). |

## Cryptography / secrets
Ed25519 only; keys by reference (env:/file:); HSM/KMS custody and mTLS transport are production requirements. **(production custody blocked: external HSM/KMS)**

## Sensitive data
Private keys never in repr/logs/config dumps.

## Failure modes

| Failure | Behaviour | Mode |
|---|---|---|
| trust store unavailable | all verification fails closed | fail-closed |
| key compromise | revoke kid; verification stops immediately; audited | fail-closed |
| replay | nonce cache rejects; full cache fails closed | fail-closed |
| clock skew | bounded +-30 s window; beyond it tokens are refused | fail-closed |

## Concurrency / idempotency / retry
Replay cache under a lock; bounded; full cache fails closed (OVERLOADED).

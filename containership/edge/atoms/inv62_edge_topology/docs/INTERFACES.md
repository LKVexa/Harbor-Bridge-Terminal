# Public interfaces (MC-012 .. MC-019, C021–C030)

Boundary inventory: the three wire protocols below (JSON over any byte transport; `TopologyService.handle(bytes) -> bytes`),
the Python admin API (`admin`, `explain`, `health`, `activate_config`, `checkpoint`, `export_state`, `import_state`),
the bootstrap CLI, the config/secret files, and the on-disk state/audit files. There is **no WIT/RPC binding in
this archive**; binding the byte boundary to a wasmCloud interface is part of MC-021.

| Protocol | Ops | Permission | Schema |
|---|---|---|---|
| `PK_TOPO_GRAPH/1` | `apply` (atomic batch: add_node, remove_node, connect, disconnect, set_link_state, probe; optional `expected_revision`), `get` | `topo.graph.write` / `topo.graph.read` | `schemas/pk_topo_graph.request.schema.json` |
| `PK_TOPO_NEAREST/1` | `resolve` (origin, capability, constraints: residency, max_latency_ms, exclude, same_site_only, prefer; explain) | `topo.nearest.resolve` | `schemas/pk_topo_nearest.request.schema.json` |
| `PK_TOPO_PARTITION/1` | `status`, `acquire`, `renew`, `validate_token` | `topo.partition.read` / `topo.partition.lease` | `schemas/pk_topo_partition.request.schema.json` |

Envelope: `protocol, op, tenant, request_id, credential, body` required; `accept_versions, required_features,
idempotency_key, deadline_ms, traceparent` optional. Response: `schemas/pk_topo.response.schema.json`.
Canonical encoding: UTF-8 JSON, sorted keys, no NaN/Infinity, no duplicate keys.

## Limits (MC-018)
256 KiB payload · depth 16 · 1 000 mutations/apply · 16 considered candidates returned · 64 excludes ·
64 capabilities/node · identifiers ≤ 128 chars · deadline ≤ 60 s · graph limits from config.

## Mixed versions (MC-017)
Server supports v1 of each family. A peer offering `FAMILY/N` with `accept_versions` gets the highest common
version echoed in `protocol`; no overlap → `TOPO.UNSUPPORTED_VERSION` with the supported list. Unknown *required*
features are refused; unknown *optional* fields are rejected by schema (strict), so additive changes require a new
minor feature flag or a new major. See `COMPATIBILITY.md`.

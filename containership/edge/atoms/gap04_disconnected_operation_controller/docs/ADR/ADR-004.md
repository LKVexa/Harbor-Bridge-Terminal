# ADR-004: Audit integrity: journal *is* the audit chain

**Status:** Proposed (2026-09-22) — requires architecture + security owner acceptance (see `../GOVERNANCE.md`). Superseding decisions must add a new ADR; this file is not rewritten in place.
**Controls:** C04 · **Modules:** runtime/journal.py

## Context
Accepted decisions must never exist without accountability evidence.

## Decision
The decision frame is the audit event (no separate write that could fail independently). Integrity = hash chain + HMAC-SHA-256 with a key held outside the journal; verifiable export (anchor, frames, head) is attached to reconciliation. Compaction preserves continuity through the MAC'd anchor.

## Alternatives considered and rejected
(a) Separate audit log — two writes, crash window between them. (b) Per-frame Ed25519 signatures — stronger non-repudiation but key on device anyway; possible future upgrade to signed checkpoints.

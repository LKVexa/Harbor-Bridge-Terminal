# ADR-001: Offline authority model: signed, scoped, expiring leases

**Status:** Proposed (2026-09-22) — requires architecture + security owner acceptance (see `../GOVERNANCE.md`). Superseding decisions must add a new ADR; this file is not rewritten in place.
**Controls:** C01, C06, C12 · **Modules:** controller.py, runtime/trust.py, runtime/node.py:install_lease

## Context
A site must act alone during partitions without being able to grant itself authority.

## Decision
Authority is a control-plane-signed `PK_SIGNED_LEASE/1` bound to trust domain + full scope (site, tenant, cluster, node class, environment), policy digest, capability set, and authority epoch. Local authority = lease capabilities ∩ tier permissions ∩ policy ∩ PLN-07 grant. Leases cannot be extended locally; renewal is a new signed lease installed while reachable and after reconciliation.

## Alternatives considered and rejected
(a) Unsigned local lease counters (4.2.0) — forgeable by any local process. (b) Symmetric HMAC leases — every verifier could mint leases. (c) X.509 certificate leases — heavier parsing surface, no benefit for purpose-bound raw keys.

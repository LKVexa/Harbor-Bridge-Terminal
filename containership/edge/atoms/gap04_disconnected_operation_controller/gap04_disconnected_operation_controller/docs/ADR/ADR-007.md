# ADR-007: Error model: stable registry, append-only

**Status:** Proposed (2026-09-22) — requires architecture + security owner acceptance (see `../GOVERNANCE.md`). Superseding decisions must add a new ADR; this file is not rewritten in place.
**Controls:** C19 · **Modules:** runtime/errors.py

## Context
Callers need machine-readable, stable failure semantics.

## Decision
`PK_GAP04_ERROR/1` with codes `GAP04-Ennnn`, category, retryable, HTTP mapping, sanitized details; registry snapshot test forbids removal/semantic change.

## Alternatives considered and rejected
Exception class names as contract (4.2.0).

## Consequences
* Security: see `../THREAT_MODEL.md` for residual risks linked to this decision.
* Operations: see `../RUNBOOK.md`.
* Compatibility/migration: persisted and wire formats are versioned; see `../../COMPATIBILITY_MATRIX.json`.
* Verification: tests referenced in `../../evidence/CHECKLIST_STATUS.json` for the controls above.

# ADR-005: Reconciliation: authoritative wins, compensate or quarantine

**Status:** Proposed (2026-09-22) — requires architecture + security owner acceptance (see `../GOVERNANCE.md`). Superseding decisions must add a new ADR; this file is not rewritten in place.
**Controls:** C07, C08, C09 · **Modules:** runtime/node.py:reconnect, runtime/adapters.py:ReferenceReplication

## Context
On reconnect local decisions may conflict with authoritative state.

## Decision
Deterministic txn id = H(site, partition epoch, audit head). Batches of `reconcile.batch_size`, each acknowledged and persisted before the next; resumable with the same txn id. Conflict ⇒ compensate through GAP-01 (idempotent); unconfirmed compensation ⇒ quarantine outcome for operator resolution. No merge functions are offered.

## Alternatives considered and rejected
(a) Last-writer-wins — unsafe for admission/scale. (b) Site wins — defeats central authority.

## Consequences
* Security: see `../THREAT_MODEL.md` for residual risks linked to this decision.
* Operations: see `../RUNBOOK.md`.
* Compatibility/migration: persisted and wire formats are versioned; see `../../COMPATIBILITY_MATRIX.json`.
* Verification: tests referenced in `../../evidence/CHECKLIST_STATUS.json` for the controls above.

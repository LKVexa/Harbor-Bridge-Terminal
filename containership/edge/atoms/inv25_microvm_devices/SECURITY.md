# Security policy — INV-25 MicroVM devices

## Supported versions
| Version | Supported |
|---|---|
| 4.3.x | yes |
| 4.2.x | security fixes until 4.4.0 |
| < 4.2 | no |

## Reporting
Report privately to the security reviewer role `@inv25-security` (contact channel PENDING owner
confirmation — do not open public issues for vulnerabilities). Include affected version, reproduction and
impact. Acknowledgement within 3 business days. Response targets: `docs/vulnerability-eol.md`.

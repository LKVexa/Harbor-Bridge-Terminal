# Capacity, Quota and Fairness (MC-008) and Capacity Model (MC-053)

Status: **Draft; limits below are enforced in code.**

| Limit | Value | Enforced by |
|---|---|---|
| Serialized state size | 16 MiB default | `durable.DEFAULT_MAX_STATE_BYTES` → `StateTooLarge` |
| Retained revisions | 1000 default | `FileStateBackend(max_revisions)` compaction |
| Graph nodes | 100 000 | `graph.MAX_NODES` |
| Config source size | 4 MiB | `config.MAX_SOURCE_BYTES` |
| Resources per tenant | 10 000 default | `TenantRegistry.enforce_quota` |
| Concurrent operations | 4 default, queue 16 | `AdmissionController` |
| In-memory audit events | 4096 | `IacState(audit_capacity)` |
| Offline queue | 100 plans, 1 h staleness | `OfflineQueue` |
| Metric series | 5000 | `MetricsRegistry(max_series)` |
| Idempotency keys | 10 000 LRU | `IdempotencyStore` |

**Fairness:** admission is FIFO-ish per process with per-tenant state isolation; per-tenant rate quotas are an estate gateway concern.

**Capacity model** (from `evidence/benchmarks.json`, regenerated by `tools/build_status.py`): per-resource p99 cost and an apply ceiling within the 0.25 s reference SLO are recorded in `evidence/capacity_model.json`. Saturation indicators: `admission queue_depth`, `shed` count, breaker state, `pk_iac_state_*` gauges, state bytes.

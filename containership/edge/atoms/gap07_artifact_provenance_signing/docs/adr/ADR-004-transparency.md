# ADR-004: Transparency service
Status: accepted (format) / open (service)
Decision: RFC 6962/9162 Merkle semantics with GAP-07 signed checkpoints (`PK_CHECKPOINT/1`) and pinned log keys. A Rekor-compatible client adapter is provided. Local verification is mandatory. Offline sites use a monotonic signed cache.
Open: run a private log versus public Rekor. Checkpoint-format bridging to C2SP signed-note is needed if Rekor v2 is chosen.

# ADR-0001 — INV-12 canonical interop engine: semantics, runtime seam and policy choices

* **Status:** Accepted for 4.3.0 (engineering); pending peer review (MC-050 gate D)
* **Date:** 2026-09-22
* **Deciders:** INV-12 maintainers (named reviewers to be recorded at review)

## Context

INV-12 4.2.0 was a Python reference model with untyped composites, a flat allow-list per language, no
canonical memory layout, no resource handles and no evidence for its latency SLO. The missing-components
checklist (MC-001 … MC-058) requires a complete semantic model, real-language fixtures and assurance
machinery.

## Decisions

1. **Specification baseline.** Component Model canonical ABI as of the WASI 0.2 line: `string-encoding=utf8`,
   `MAX_FLAT_PARAMS=16`, `MAX_FLAT_RESULTS=1`, u8/u16/u32 discriminants, flags packed into u8/u16/u32 words,
   `own`/`borrow` handles as i32 table indexes. Async (`future`/`stream`) follows the reference state machines
   in `canon/async_model.py` and is gated off by default (`features.async=false`).
2. **Stricter than upstream where it is safe:** undeclared flag bits are rejected on lift; zero-size-element
   lists above 1 000 000 items are rejected. `bool` lift keeps the upstream rule (non-zero is true).
3. **No shared memory, ever.** The no-shared-memory interpretation is literal: copy-in on lower, copy-out on lift,
   no host view retained into guest memory. `zero_copy` is a config gate that validation refuses to enable.
4. **BigInt policy.** JavaScript maps `s64/u64` to `bigint` only; `Number` is never used for 64-bit values.
   Number→integer conversion is permitted only for safe integers.
5. **NaN policy.** NaN payloads are canonicalized; ±0 and ±∞ are preserved.
6. **Unicode policy.** Scalar values only, strict UTF-8, no normalization.
7. **Language profiles.** Rust, Go, JavaScript, Python are certified via the golden corpus and the 16-pair
   matrix; Go refuses `future`/`stream` until a binding exists.
8. **Runtime seam.** `canon.boundary.Instance` (memory + realloc + table + exports) is the seam a production
   runtime implements. Evidence today: the in-process reference adapter and a real WebAssembly guest (Go →
   wasip1) executed by V8 through `tools/wasm_host.mjs`. A Wasmtime component-API adapter is the production
   target and is not shipped (no crates/PyPI access in the build environment).
9. **Trust primitives.** HMAC-SHA256 (stdlib) for config approvals, audit seals and capability tokens.
   Production target: asymmetric signatures (Ed25519/Sigstore) with a transparency log.

## Alternatives rejected

* *Keep type allow-lists per language* — cannot express nested types or refusals; replaced by a registry.
* *Deep-copy host objects via `copy.deepcopy`* — executes user hooks; replaced by exact-type cloning.
* *Normalize strings to NFC* — silently changes bytes; rejected (callers normalize explicitly).
* *Zero-copy same-language fast path* — violates the no-sharing SLO; kept as an uncertified, disabled gate.
* *Number-backed JS 64-bit integers* — lossy above 2^53; rejected.
* *Ignore undeclared flag bits (upstream behaviour)* — hides corruption; rejected in favour of fail-closed.

## Consequences

The engine is complete as a specification and reference implementation with cross-language evidence. The
production runtime binding, signed releases, ARM64/macOS/Windows certification and the `pk_core` gate remain
open and are tracked as blocked controls rather than claimed.

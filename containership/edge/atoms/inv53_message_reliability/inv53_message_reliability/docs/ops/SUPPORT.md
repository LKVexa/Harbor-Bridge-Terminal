# Production support commitments (C091)

Proposed, pending a service_owner: support hours per `INCIDENT_PLAYBOOK.md`; supported versions per
`docs/spec/COMPATIBILITY.md`; a support request must include the version, config digest, `health()` output,
and the relevant audit/record ids — never payloads or keys. Out of scope: consumer business logic, message
ordering, broker products other than the INV-54 adapters.

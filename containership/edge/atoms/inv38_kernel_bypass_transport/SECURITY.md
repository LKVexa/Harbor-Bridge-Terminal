# Security policy (INV-38-C094)

## Reporting
Report vulnerabilities to the security team via the org's coordinated-disclosure
channel (secure contact resolved out-of-band; no address is embedded here).

## Supported versions
See `compatibility/SUPPORTED_VERSIONS.md`. Only supported versions receive
security fixes.

## Handling
Triage, severity assessment, emergency-patch criteria and EOL are defined in
`docs/PATCH_AND_EOL_POLICY.md`. DMA/isolation-critical issues are treated as
highest severity.

# ADR-0002 … ADR-0006 (v4.3.0)

All: Status **ACCEPTED-FOR-REFERENCE / PENDING OWNER APPROVAL**, date 2026-09-22, re-review 2027-03-22 or on a
major provider/protocol/state-model change. Approver field is empty until an accountable owner signs (WS 16).

## ADR-0002 — `pk_core` dependency
Decision: the control plane (`controller`, `store`, `authz`, …) has **no** `pk_core` dependency. `pk_core` is an
optional extra (`[inventory]`) used only by `component.py`/`contract.py`; those symbols load lazily.
Consumed API: `pk_core.contract.{Contract, Dependency, Slo}`, `pk_core.checklist.{ChecklistItem, Finding}`,
`pk_core.component.Component` (methods `assess_implementation/assess_security/assess_resilience`,
`satisfied`, `_evidence`, `assess_all`). Compatible range declared `>=1.0,<2.0` — **BLOCKED**: no released,
hash-pinnable `pk_core` artifact was supplied, so the pin and its hash cannot be recorded.

## ADR-0003 — single vs distributed controller
Decision: one writer per **host**, enforced by lease epoch = fencing token. `FileLeaseStore` (flock CAS) is
correct for single-node / shared-FS deployment. Multi-site requires a consensus store (etcd/ZooKeeper/Consul)
implementing the `LeaseStore` protocol — BLOCKED on platform choice. Partition policy: FROZEN_WRITE.

## ADR-0004 — identity and authorization
Decision: signed, audience-bound, short-lived credentials (`inv32tok`, HMAC-SHA256, kid rotation) with
jti/principal revocation and ±30 s skew; deny-by-default capability policy; elevated actions for revert,
quarantine, config, emergency, audit export, secret access; break-glass ≤ 900 s with mandatory reason. The
production identity provider, mTLS PKI and asymmetric token signing (so verifiers cannot mint) are BLOCKED on
platform PKI selection — the HMAC scheme is a reference implementation.

## ADR-0005 — durable state technology
Decision: append-only checksummed JSONL WAL + atomic snapshot + segmented SHA-256 hash-chained audit with
HMAC-signed segment heads and external anchors. Chosen for zero dependencies and auditable format. Encryption
at rest delegated to an encrypted volume (BLOCKED: deployment). Distributed deployments need a replicated
store (BLOCKED with ADR-0003).

## ADR-0006 — schema technology
Decision: JSON Schema 2020-12 for all external payloads (`schemas/`), with a stdlib validator subset and
published conformance vectors. Protobuf/WIT not selected because no RPC framework is in scope yet; the JSON
Schemas are the normative source for any future IDL generation.

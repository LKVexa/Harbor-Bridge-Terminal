# INV-37 threat model

**Version:** 4.3.0 · Method: STRIDE per boundary (INTERFACES.md §1) · Owner: security_owner · Review: every release and on any new boundary. Covers INV-37-C041, C050, C087. Each threat maps to a control and a test; `—` in the test column means the control is not verifiable in-repo and is carried to the production gate.

| ID | Actor / vector | STRIDE | Boundary | Threat | Control (4.3.0) | Test | Residual |
|---|---|---|---|---|---|---|---|
| T01 | Malicious tenant | Tampering | B3 | Corrupted chunk accepted | per-chunk SHA-256 + geometry | test_data_plane, conformance `chunk.invalid.*` | none known |
| T02 | Malicious tenant / control plane | Tampering | B2 | Manifest substitution / reordering | object digest over ordered list; schema/geometry checks; manifest copied at validation | conformance `manifest.invalid.*`, fuzz | manifest metadata not signed by control plane (see T15) |
| T03 | Compromised producer | Tampering (TOCTOU) | B5 | Mutate shared region after commit | final in-place re-hash before read-only view; quarantine | test_transport `post_commit_mutation` | producer can still cause DoS by corrupting |
| T04 | Other tenant | Info disclosure | B5 | Attach to another tenant's region | per-transfer region; HMAC-bound descriptor; tenant/transfer match; revocation | test_transport `descriptor_binding`, `revoked` | OS-level shm name guessing still needs same-UID; run tenants under distinct UIDs/IPC namespaces (deployment) |
| T05 | Any caller | Spoofing | B1 | Forged / altered token | HMAC-SHA256, constant-time compare, generic error | test_security `forged`, fuzz tokens | shared-key model: key compromise = full compromise (T14) |
| T06 | Network attacker / insider | Replay | B1, B4 | Replay single-use token or resume token | nonce cache for `once` tokens (live nonces never evicted; full cache fails closed); RESUME/2 MAC + age + epoch | test_security `replay`, test_integration `reconcile` | multi-use tokens replayable within TTL by design (short TTL) |
| T07 | Data-plane / tenant-admin principal | Elevation | B1 | Use data token for admin actions; tenant admin freezing the node | admin/data minted separately; node-scoped actions (`freeze`, `administer`) need a global (`*`) admin; deny-by-default per call | test_security `matrix`, test_integration `operator_controls` | — |
| T08 | Tenant A | Elevation / info | B1 | Cross-tenant access by transfer id | authz binds tenant + scope on every call | test_integration `authorization_on_every_call` | — |
| T09 | Tenant | DoS | B1 | Exhaust slots/memory/storage | global ceilings, tenant quotas, fair admission, pending bound, checkpoint quota, mapped-bytes cap | test_quota, test_checkpoint `storage_quota` | CPU exhaustion via hashing bounded only by admission |
| T10 | Local attacker | Tampering | B8 | Edit checkpoint to claim unverified chunks | HMAC seal; re-hash on load; quarantine | test_checkpoint `broken_seal`, `corrupt_data` | attacker with key-file access can forge seals |
| T11 | Stale node | Tampering | B8 | Split-brain duplicate owner writes | fencing epoch checked under a cross-process flock on every write | test_checkpoint `fencing`, test_integration `restart_resume` | flock is advisory and node-local: on network filesystems (NFS) it may not exclude other hosts; Windows has in-process locking only |
| T12 | Insider | Repudiation | B9 | Delete/alter audit trail | hash chain + MAC; start refuses broken chain | test_security `AuditTest` | truncation of the tail is only detected against an external anchor (ship to SIEM) |
| T13 | Operator error | Tampering | B6 | Unsafe config (auth off, huge limits) | invariants, preflight fatal rules, atomic activation, rollback | test_config | inline-secret detection is by key name; a secret stored under an innocuous key name is not detected |
| T14 | Supply chain / secret theft | Info / spoofing | B7 | Key exfiltration | 0600 check, no inline secrets, rotation/revocation API | test_config `key_file_permissions`, test_security `rotation` | no HSM/KMS integration (external) |
| T15 | Compromised control plane | Spoofing | B2 | Manifest from unauthenticated source | token authn for `create-transfer` | test_integration | manifest not signed end-to-end; mTLS/attestation not implemented → gate `mtls_or_workload_identity` |
| T16 | Supply chain | Tampering | package | Malicious dependency | zero runtime deps; pin check; SBOM with file hashes | test_gates `test_pins` | artifact signing/attestation external → gate `sbom_signed_artifact` |
| T17 | Hostile input | DoS / crash | B2–B6 | Parser crash / unclassified exception | strict parsing; fuzzing invariant | test_fuzz (~6,500 cases per run; `INV37_FUZZ_ITERS` to extend) | coverage-guided fuzzing (atheris) not run |
| T18 | Timing attacker | Info | B1 | Digest/MAC timing oracle | `hmac.compare_digest` everywhere | inspection | Python-level side channels (cache, allocation) not analysed |
| T19 | Co-tenant | Info (side channel) | B5 | Page-cache / memory side channels | per-tenant regions, no pooling | — | not analysed; requires hardware isolation review |
| T20 | Time-service outage | DoS / spoofing | B1 | Accept expired tokens when clock fails | clock failure → `security_service_unavailable` | test_security `time_service_failure` | clock skew attacks within `clock_skew` |
| T21 | VM guest | Escape | host/guest | Guest reaches host memory via shared mapping | host/guest path not implemented; fails closed | test_transport `selection_fails_closed` | becomes relevant with phase-2 ADR |
| T22 | Log consumer | Info | B10 | Tenant data in logs | pseudonymised tenant ids, field redaction, no payload/tokens | test_telemetry, test_integration `observability_surfaces` | — |

Least privilege (C042): capabilities are per action and per scope; tokens can be scoped to a single transfer (`scope`) and node (`node`); admin tokens are separate. Ambient authority (C043): the package opens only the configured checkpoint directory, audit/log paths and key file; it starts no listeners, spawns no processes, loads no plugins and reads no environment variables except `INV37_BUILD_COMMIT`/`INV37_NODE_ID` (lineage labels). Kernel/device authority: none beyond POSIX shm.

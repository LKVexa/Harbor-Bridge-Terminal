# hold/

The DF scaffold, byte-identical to `Desktop/DF Containers`: four node containers (the engines) and DF_Fabric. `HOLD_DIGEST.json` pins the zips; `BUILD` extracts them into `_engines/`, re-checks each container's own sums, builds the three C engines and binds all four. `DF_INDEX.md` is the DF set's own index.

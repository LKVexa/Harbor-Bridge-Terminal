# vm_xtra_large / DF_Fabric -- fabric slot

The berth's fabric: `fabric/BERTH_FABRIC.pal` (identical to `../BERTH.pal`), the engine registry `fabric/NODES.json`, this container's own .tif fabric (`fabric/GENESIS.fabric.tif` + `fabric/FABRIC.json`, sealed; the live image `_fabric/DF_Fabric.fabric.tif` is state, outside the seal) and the three launchers. `./RUN` ticks the berth's fabric: every container's picture is read, executed on its engine, and written back as a new frame; this container's picture records the federation vote, the four accumulators and the sealed event log. `./RUN --sealed` executes the sealed bundles instead: BERTH.pal in one lowering per engine (replica + BSP), CARGO.pal (5521 rows) in 66 segment(s) (replica per engine, and a pipeline chained across engines).

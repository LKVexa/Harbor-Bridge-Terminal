# schemas/

JSON schemas for every ship artifact; VERIFY (U0.5) and every berth battery (B1) validate against them with the stdlib-only validator in `ship/unikernel/ucschemas.py`.

* `UC_BERTH.json`
* `UC_BILL_OF_LADING.json`
* `UC_CAPABILITY_LEDGER.json`
* `UC_FABRIC.json`
* `UC_GATE_RESULTS.json`
* `UC_HOLD_DIGEST.json`
* `UC_HULL_DIGEST.json`
* `UC_NODE_SLOT.json`
* `UC_SHIP_MANIFEST.json`
* `UC_SORT_LEDGER.json`
* `UC_SORT_POLICY.json`
